# Fig.Feed

Aplicação web para social medias montarem e organizarem feeds, carrosséis e cronogramas de forma visual: arraste um post e a grade se reorganiza sozinha, como o auto layout do Figma.

## Versões

- `index.html` — versão 2, seguindo os layouts do Figma: Home, Menu, Contas, Feed, Carrossel, Editar texto e Download.
- `prototipo-v1.html` — primeiro protótipo, com Contas, Feed, Stories e Cronograma.

## Como abrir

Baixe o arquivo e abra com dois cliques no navegador. As fotos de exemplo vêm do Unsplash (via Lorem Picsum) e precisam de internet.

Os dados ficam salvos só no navegador em que você abrir.
